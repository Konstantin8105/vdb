# vdb
vector db


---------

Дано:

1)   Предположим размер контекстного окна 8000 токенов
2)   Документ на 100000 токенов

# Стратегия 1

Разбиение документа на части по 8000 токенов с перекрытием частей.

# Стратения 2

Разбиение документа на части по 8000 токенов с перекрытием частей.
А каждую часть на мини-части по 1000 токенов.
При этом поиск может быть и по векторам части и мини-части.

# Стратегия 3

Разбиение документа на мини-части по 1000 токенов с перекрытием частей.
При этом для каждой мини-части сохраняется её положение в документе.
При поиске по вектору - можно возвращать часть документе до и после положения мини-части.

# Стратегия 4

При выполенении разбиении документа сохранять последовательность, для того чтобы позже можно было бы "ходить" по документу.
